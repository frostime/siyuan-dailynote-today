# 日记文档优先视图变更规格

## 问题陈述

当前 Daily Note View 混淆了笔记本、日期、文档和创建动作，导致空栏失控、导航无反馈、创建入口重复和上下文重复选择。

本变更分别支持两种不同任务：固定日期查看若干笔记本，以及固定笔记本连续浏览日期。两者不强行共用同一套交互模板。

## 核心方案

### 单日

- 固定一个自然日，通过笔记选择面板决定要显示的笔记本。
- 单选时点击一个笔记本立即只显示该栏；多选时应用所选集合，每个笔记本对应一个栏位。
- 所选笔记本当天没有日记时，显示目标明确的未创建栏。
- 日期箭头每次移动一个自然日，笔记本选择保持不变。

### 时间轴

- 固定一个明确的笔记本；笔记选择面板在此模式下只允许单选。
- 日期窗口包含 `1 / 2 / 3 / 5` 个日期位置。
- “逐日”保留连续自然日和未创建栏。
- “仅已有”跳过没有日记的日期，对应 issue #220。
- 日期箭头每次把窗口移动一个日期位置。

### 日历

- 日历始终显示全部笔记本，不设置笔记本范围。
- 周、月负责发现日记；年视图只负责月份导航。

不保留卡片，也不保留“单篇 / 分栏”切换。内容区统一使用日记栏位。

## 行为契约

### 单日栏位

- 只为用户明确选中的笔记本生成栏位，不自动加入其他笔记本。
- 已有日记显示文档；没有日记显示未创建栏。
- 单选或多选结果至少包含一个笔记本。
- 从单选进入多选时，默认选中当前日期所有已有日记的笔记本；若当天没有日记，则保留原单选笔记本。应用后选择保持固定，不随日期自动变化。
- 栏位顺序遵循笔记本的稳定顺序，并在日期移动时保持。
- 栏位数量由选中的笔记本数量决定，不提供栏数设置。

### 时间轴栏位

- 每栏属于同一个笔记本，不同栏对应不同日期。
- “逐日”下，设置 3 个日期就严格显示 3 个连续自然日。
- “仅已有”下，只要已有日记不少于设置数量，窗口保持完整；最后一个完整窗口之后禁用下一步。
- 一栏与多栏使用同一组件和创建逻辑。

### 栏位宽度

复用现有 `DailyNoteViewLaneMinWidth` 设置：

- 所有栏位均不小于该宽度。
- 栏位能放下时平均铺满内容区。
- 放不下时保持最小宽度并横向滚动。
- 视图内不增加第二个栏宽控件。

### 未创建栏与创建

未创建栏必须显示：

- 当前笔记本和日期；
- “未创建”状态；
- 预计创建路径；
- 一个直接创建动作；
- 浏览不会自动创建的说明。

点击创建时继承该栏的日期和笔记本，不再询问。创建成功后在原栏显示文档；允许短暂加载。

### 日历点击

- 点击 Notebook Tag：直接进入该笔记本当天的日记；重复日记进入现有冲突视图。
- 点击 Cell 空白：打开该日期的操作 Dialog，不直接创建或跳转。
- Dialog 日期固定，不再次询问日期。
- Dialog 列出全部笔记本；每个笔记本一行：已有日记提供“打开”，未创建提供“创建”。

### 控件

始终直接可见：

- 内容 / 日历
- 当前模式有效的日期导航
- 内容模式下的单日 / 时间轴
- 内容模式下，工具栏最右侧的“笔记状态”按钮

“笔记状态”按钮显示当前选择摘要；点击后打开覆盖内容的悬浮面板。面板负责单选、多选、搜索和展示各笔记本在当前内容上下文中的状态。单选立即生效，多选确认后统一应用。日历模式不显示该按钮。

右下角悬浮入口只在当前存在次级参数时显示：

- 时间轴：日期数 `1 / 2 / 3 / 5`、逐日 / 仅已有
- 日历：周 / 月 / 年
- 单日：无次级参数，不显示入口

## 重复日记

沿用现有规则：同一笔记本同一天的多篇日记视为一个冲突栏位，默认显示最早创建的文档，并提供打开其他重复文档的动作。

## 原型边界

同目录的 `daily-note-document-first.html` 只表达控件职责、栏位状态和操作结果，不是视觉规范或实现模板。

不得照搬其 DOM、CSS、尺寸、演示数据或临时脚本。实现与 SiYuan API、现有组件或真实数据冲突时，以本规格的用户行为为准；行为不明确时必须先请求用户决策。

## 代码入口

- `daily-note-view.svelte`：统一模式状态与笔记本范围。
- `view-toolbar.svelte`：日期导航和笔记状态入口。
- `content-lanes.svelte`、`daily-note-lane.svelte`：已有与未创建栏。
- `calendar-grid.svelte`：日历和日期操作 Dialog。
- `state.ts`、`resolver.ts`：日期、查询、重复分组和创建数据。

不得建立第二套平行状态或创建机制。

## 实现决策

- 单日笔记本集合与时间轴单个笔记本分别保存，不用一个字段承担两种含义。
- 日期窗口起点、“仅已有”和日期数分别表达。
- 日期箭头直接移动当前模式定义的日期，不通过不可见状态间接改变画面。
- 同一个创建目标在同一状态下只能出现一个入口。

## 验收标准

- 单日单选可立即切换一个笔记本；多选应用后稳定显示所选栏位，未创建笔记本显示可创建栏。
- 单日日期移动后保持同一笔记本集合和顺序。
- 时间轴只绑定一个笔记本；逐日与仅已有行为符合定义。
- 时间轴设置 3 个日期时，在数据足够的情况下稳定显示 3 栏。
- 栏位遵循现有最小宽度设置，空间不足时横向滚动。
- 未创建栏直接创建，不重复询问日期和笔记本，并在原栏显示新文档。
- 笔记状态面板可搜索并明确显示各笔记本当前是否有内容，不在工具栏平铺全部笔记本。
- 日历始终显示全部笔记本；Notebook Tag 直接打开日记，Cell 空白打开包含全部笔记本的操作 Dialog。
- 页面不存在职责相同的多个创建入口。
- 卡片及“单篇 / 分栏”状态、文案和样式已移除。
- 项目构建通过。

## 待确认边界

以下情况出现时必须询问用户：

- 需要脱离当前上下文创建其他日期或其他笔记本的日记。
- 周/月查询需要分页或渐进加载。
- 历史日记缺少 Daily Note 属性，需要兼容或修复。

## 术语表

**单日笔记本集合**：单日模式下通过单选或多选确定的一个或多个笔记本。

**日期位置**：时间轴中的一个位置；可代表自然日或开启过滤后的已有日记日期。

**日期窗口**：时间轴当前同时显示的若干日期位置。

**未创建栏**：日期和笔记本已经明确、但日记尚不存在的可创建栏位。
